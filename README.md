# ปัญหาทางกฎหมายเกี่ยวกับการนำบทบัญญัติว่าด้วยการคุมขังตามประมวลกฎหมายวิธีพิจารณาความอาญามาใช้บังคับโดยอนุโลมแก่การไต่สวนของคณะกรรมการ ป.ป.ช. ตามมาตรา 39

สารนิพนธ์ น.ม. กลุ่มวิชากฎหมายอาญาและกระบวนการยุติธรรมทางอาญา คณะนิติศาสตร์ มหาวิทยาลัยศรีปทุม

## โครงสร้าง repo (เหมือน `nacc-flagrant-arrest-thesis`)

| path | เนื้อหา |
|---|---|
| `HANDOVER.md` | สรุปบริบทงานวิจัย ปัญหา สถานะการตรวจ และงานค้าง (ใช้เริ่ม chat ใหม่) |
| `CLAUDE.md` | กฎการทำงานและสถานะล่าสุด |
| `src/` | (ว่าง) ไม่ใช้ เนื้อหาแก้ที่ `draft/original.html` และ `draft/src/chN.txt` |
| `docs/index.html` | หน้าเว็บฉบับร่างแบบเรียบ (สร้างจาก `draft/original.html`) ป้าย (รอตรวจสอบ) = แหล่งที่ยังไม่ยืนยัน |
| `draft/original.html` | ไฟล์ร่างต้นฉบับ (แหล่งความจริงของเนื้อหา) |
| `draft/src/` | ต้นฉบับข้อความแต่ละบท (`ch1.txt` ...) ใช้กับ `tools/build2.py` |
| `tools/` | `make_page.py` แปลงร่างเป็นหน้าเว็บ, `build2.py` สร้างบท, `pending.json` รายการป้ายรอตรวจสอบ |
| `sources/` | ทะเบียนแหล่ง (`INDEX.md`), `statutes/` ตัวบทที่ยืนยันแล้ว, `excerpts/` ข้อความตัดตอน/สรุปแหล่ง, PDF ที่ผู้ใช้อัปโหลด |
| `research-notes/` | บันทึกการอ่านแหล่ง (คัดลอกจากรีโปเดิมเฉพาะบันทึกที่เป็นกลางต่อหัวข้อ) |

## สร้างหน้าเว็บใหม่

```
python3 -I tools/make_page.py draft/original.html docs/index.html
```

เมื่อตรวจแหล่งใดเสร็จ ให้ลบรายการนั้นออกจาก `tools/pending.json` แล้วสร้างใหม่
